gpu-dev Precision Split

Apple Silicon unified memory: double stays on CPU (MSL rejects double), float32 on GPU, zero-copy handoff. w-layer inversion at rel_rms ~1e-05 vs ducc0.

Why this split is forced

  • • MSL rejects double: GPU stages must be provably float-safe
  • • Phase args reach ~300 rad: range-reduce in double on CPU
  • • 1% dw error visibly drifts w-interpolation: layout stays double
  • • Zero-copy measured: 11.5 GB/s, no sync calls anywhere

Gates (all passing unless noted)

  • • kernel eval abs/rel 4.5e-6
  • • grid rel_max/rms ≤ 5e-5 (measured 1.8e-5)
  • • roundtrip degrid ≤ 5e-5 · adjoint 2.9e-07
  • • w-layer image vs ducc0: rel_rms ~1.3e-05
